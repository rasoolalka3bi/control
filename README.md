# تطبيق أندرويد - إدارة أجهزة البصمة

## هذا التحديث ينفّذ 3 إصلاحات

### 1) ذكر حالة كل جهاز صراحة (لحد 3 أجهزة)
بدل التركيز على الأجهزة اللي فيها مشكلة بس، الإشعار دلوقتي (لو عدد الأجهزة
3 أو أقل) بيذكر **كل جهاز بجملته الخاصة**، حتى السليم منهم:
- `جهاز الموظفين غير متصل`
- `جهاز المسؤولين متصل لكن غير متزامن`
- `جهاز الفرع الرئيسي متزامن`

كلها في سطر واحد مفصولة بشرطة. لأكثر من 3 أجهزة، يترجع النظام للتركيز على
المشاكل فقط (بالاسم أو بالعدد) تفاديًا لسطر طويل جدًا.

### 2) إصلاح باگ: "غير متزامن" حتى بعد المزامنة التلقائية
السبب الحقيقي: الكود كان بيصحح وقت الجهاز فعليًا وقت المزامنة، لكن مبيمسحش
علامة "الانحراف" فورًا — كانت بتفضل شايلة القيمة القديمة لحد دورة الفحص
القادمة (حتى دقيقة كاملة). الآن `_sync_single_device` بيصفّر العلامة فورًا
بمجرد نجاح المزامنة.

### 3) التفرقة الواضحة بين "غير متصل" و"متصل لكن غير متزامن"
بدل "يحتاج مزامنة" الغامضة، الصياغة بقت أدق: **"غير متصل"** (مش قادرين
نتأكد من وقته أصلاً) مقابل **"متصل لكن غير متزامن"** (متصل لكن وقته منحرف
فعليًا) - حالتان مختلفتان تمامًا برسالتين مختلفتين.
