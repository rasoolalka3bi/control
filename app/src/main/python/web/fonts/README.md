# مطلوب: أضف ملف الخط هنا يدويًا

⚠️ **هذه الخطوة ضرورية** — بدونها سيظهر اسم "رسـول الـڪـعـبـي" بخط افتراضي عادي
بدل الخط الكوفي، لأن بيئة العمل التي بنيت بها المشروع لا تملك اتصال إنترنت لتنزيل
ملفات الخطوط تلقائيًا.

## الخطوات (تأخذ دقيقتين)

1. افتح الرابط: https://fonts.google.com/specimen/Reem+Kufi
2. اضغط **"Download family"** (زر التنزيل أعلى يمين الصفحة)
3. فك ضغط الملف الذي نزل (ZIP)
4. جوه المجلد المفكوك هتلاقي عدة ملفات بصيغة `.ttf` — دور على الملف اللي اسمه
   قريب من: `ReemKufi-Bold.ttf` (أو `static/ReemKufi-Bold.ttf` لو كان جوه مجلد فرعي)
5. انسخ هذا الملف بالتحديد إلى نفس المجلد اللي فيه ملف README.md ده
   (يعني المسار النهائي يكون: `app/src/main/python/web/fonts/ReemKufi-Bold.ttf`)
6. تأكد إن اسم الملف بالظبط `ReemKufi-Bold.ttf` (لو الاسم مختلف، غيّر اسمه ليطابق ده،
   أو عدّل المسار في ملف `index.html` داخل قسم `@font-face` ليطابق الاسم الفعلي)

## لو نسيت تضيفه
التطبيق هيشتغل عادي بدون أي خطأ — بس اسم حقوق الملكية هيظهر بخط عربي عادي
(fallback) بدل الخط الكوفي المقصود.
